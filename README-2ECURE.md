# 2ecure Messenger for iOS

This repository is **2ecure Messenger**, a rebranded fork of
[Element X iOS](https://github.com/element-hq/element-x-ios) for the private,
invite-only Matrix service at [2ecure.com](https://2ecure.com).

- Upstream base: `release/26.09.2` (commit `47f881c`), imported unmodified as the first commit.
- Every later commit is a 2ecure change (branding, service lock-in, push gateway, privacy defaults).
